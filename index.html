Put the firmware on the board

One-time step for each ItsyBitsy M4. Nothing to install on your computer.

1. Download

led_iv_lab.uf2 — the latest build of the Arduino firmware.

2. Bootloader mode

Plug the board in over USB and press the reset button twice, quickly. The onboard LED turns a slow-pulsing colour and a drive called ITSYM4BOOT appears.

3. Drag and drop

Copy led_iv_lab.uf2 onto ITSYM4BOOT. The drive disappears and the board restarts running the lab firmware.

4. Connect

Scroll up and click Connect to board. Pick the port named ItsyBitsy M4 (or USB Serial Device on Windows).

Prefer CircuitPython? A matching code.py speaks the same protocol — the page works with either. The full command set is in PROTOCOL.md; type HELP in the serial log to see it from the board.
